## ⚡ Deployment to GitHub Pages

1. Commit and push the repository to GitHub:
   ```bash
   git add .
   git commit -m "Build modern portfolio with AI avatar and verified credentials"
   git push origin main
   ```
2. Navigate to your repository settings on GitHub:
   - Go to **Settings** > **Pages**.
   - Under **Build and deployment** > **Source**, select **Deploy from a branch**.
   - Select branch: `main` and folder: `/ (root)`.
   - Click **Save**.
3. Your site will be published at: `https://sravankumargandhe15-png.github.io/Portfolio/`!
